## 💼 Current Role

**Junior Research Assistant** · Vandhana International Pvt. Ltd. · 2026 – Present

I work on railway and metro track and rolling-stock inspection, combining field measurement with Python-based data analysis.

| | Work | What it involves |
|:-:|---|---|
| 🛞 | **Wheel profile analysis** | Python pipeline that parses MiniProf exports, aligns wheel profiles to a reference using ICP (Kabsch/SVD), computes signed wear depth, and generates per-wheel plots and a fleet-wide wear heatmap |
| 🚆 | **Rail profile alignment** | Automated alignment of measured rail profiles against the UIC 60 standard using coarse-to-fine optimisation and KD-tree matching |
| 📱 | **Track inspection app** | Android app (Jetpack Compose) using rotation-vector sensor fusion for track alignment and geometry checks |
| 📡 | **GPR + deep learning** | Exploring detection of buried utilities during ballast cleaning (gprMax synthetic data, YOLO/U-Net, Jetson Orin edge inference) |
| 📊 | **Field work & reporting** | Rail grinding machine field operations, plus consolidating test-site data into zone-wise Excel reports |
